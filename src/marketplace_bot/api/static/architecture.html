Live Navigator Companion is a hybrid UI navigator for dense web workspaces. The browser stays local, the hosted planning path runs on Google Cloud, and the user works directly inside the live site.

System Architecture

This view answers the deployment question: what runs in the browser, what runs on the operator machine, and what runs on Google Cloud.

Session Lifecycle

This view answers the product question: how a session moves from setup to indexing, review, map inspection, live notes, safe actions, and resume.

Core Features

  • Two runtime modes: complex_workspace and review_only.
  • Structure checklist and coverage accounting.
  • Full review tab and map or coverage inspector.
  • Inline Live Notes for complex workspaces.
  • Saved sessions, resume, partial refresh, and full refresh.
  • Review-first behavior with optional safe execution.

Google Stack

  • Cloud Run hosts the backend path.
  • Google GenAI SDK drives the planner path.
  • Gemini or Vertex AI provides multimodal reasoning.
  • Firestore stores session memory.
  • Cloud Storage stores artifacts and evidence.
